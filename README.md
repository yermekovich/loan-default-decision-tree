# Loan Default: деревья решений (Gini vs Entropy)

Предсказание дефолта по кредиту деревьями решений с критериями Gini и Entropy, визуализация первых уровней дерева. Датасет: Loan Default (76 605 наблюдений в тестовой части).

## Результат и важное замечание
Accuracy около **0.88**, но она вводит в заблуждение: класс дефолта редкий (около 12%), и для него **recall всего 0.03** при precision 0.58. Модель почти не находит дефолтных клиентов, то есть в реальной задаче она бесполезна.

## Что стоило бы сделать дальше
`class_weight='balanced'` или передискретизация, подбор порога по precision-recall кривой, метрики PR-AUC и F1 по миноритарному классу, ансамбли (случайный лес, градиентный бустинг).

## Запуск
Откройте `pract.ipynb` в Jupyter (файл `Loan_default.csv` нужно положить рядом).
